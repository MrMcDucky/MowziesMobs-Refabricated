# Mowzie's Mobs Refabricated Unofficial

Unofficial Fabric port of Mowzie's Mobs for Minecraft 1.21.1.

This source tree is the `1.0.0` release-ready. Distribution remains subject to the original Mowzie's Mobs license and any required permission from the original author.

## Requirements

- Minecraft 1.21.1
- Fabric Loader 0.16.7 or newer compatible release
- Fabric API 0.116.7+1.21.1 or newer compatible 1.21.1 release
- GeckoLib 4.8.3 or newer compatible GeckoLib 4 release
- Java 21 JDK for building

Porting Lib 3.1.0+1.21.1 is bundled inside the produced mod JAR and does not need to be installed separately.

## Runtime dependencies

Install the release JAR alongside Fabric API and GeckoLib. Do not install a separate Porting Lib solely for this mod; a compatible Porting Lib is already nested in the JAR.
